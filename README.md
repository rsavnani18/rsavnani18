🚀 About Me

Hey! I'm Rahul Savnani, an independent AI-Assisted Developer from Ahmedabad, Gujarat, India 🇮🇳.

I'm passionate about building practical software, modern web applications, developer tools, AI-powered solutions, and open-source projects.

I see AI as a development partner that helps me explore new technologies, improve workflows, understand complex concepts, and turn ideas into working products.
